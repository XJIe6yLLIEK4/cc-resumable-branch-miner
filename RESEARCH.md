# Почему отдельная программа

Проверка исходников выполнена 14 октября 2026. Это сравнение найденных кандидатов,
а не утверждение, что на GitHub невозможно найти другие подходящие решения.

| Проект | Полезные возможности | Почему не выбран как полное готовое решение |
|---|---|---|
| [Turtle Toolbox](https://github.com/Pyroxenium/turtle-toolbox) | Сохранение задания, боковые тоннели, старая база обслуживания | В Branch Miner нет встроенного обхода рудных жил. При `pendingMotion` Runner блокирует продолжение; интерфейс отключает Resume без готового механизма восстановления. |
| [Actually Useful Turtles](https://github.com/helpmyRF24isntworking/computercraft) | GPS, задачи, карта, централизованное управление | В `Miner:initialize()` при неудачном запросе станции вызывается `setHome(self.pos.x,self.pos.y,self.pos.z)`. Это нарушает требование никогда не назначать место остановки новой базой. |
| [Mastermine V.2](https://github.com/Nick1st/Mastermine-V.2) | Сеть добывающих черепах, GPS, центральное управление | Существенно другой сценарий развёртывания. В изученной файловой системе черепахи не найдено полноценной постоянной контрольной записи её текущего обхода жилы. Полное совпадение требований не подтверждено. |
| [Исходный Branch Mining](https://github.com/mingjing04/cc-tweaked-miner) | Тоннели и добыча жил | Проверенная программа хранит позицию и ход добычи в памяти; продолжение и разгрузка на базу отсутствуют. |

Проверенные коммиты: Turtle Toolbox — `7a64f671be1ccc7fb4405fbc83123c8cb1ea5b7e`,
Actually Useful Turtles — `cc7d9e209700e179a37b445cefa1267bd97ae76e`,
Mastermine V.2 — `80a338e7d9dce6e3018ab2f0ad1db0004d01b56d`.
Актуальный `branchMining.lua` в исходном репозитории совпал с проверенной программой.
Новая реализация написана отдельно, без включения кода этих проектов.
Сохранена геометрия исходного Branch Mining, добавлены журналирование,
неизменная база, обслуживание и проверяемое продолжение.

Общее ограничение CC:Tweaked — отсутствие автоматического сохранения Lua-стека
при выгрузке — описано в [обсуждении разработчиков](https://github.com/cc-tweaked/CC-Tweaked/issues/535).
Автозапуск использует [официальный механизм startup.lua](https://tweaked.cc/guide/startup.html).
